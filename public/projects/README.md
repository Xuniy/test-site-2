Project photo folders
=====================

Put each project's gallery photos in its matching folder.

Use these filenames:

- 01.jpg
- 02.jpg
- 03.jpg
- 04.jpg
- 05.jpg

Recommended source size:

- 2400 x 1500 px for the main gallery ratio.
- Minimum: 1600 x 1000 px.
- Use landscape images with the important subject near the center.
- JPG is best for photos; WebP is also fine if you update the paths in src/App.tsx.

The site displays images with object-fit: cover, so all photos in a project should use a similar landscape crop to avoid awkward cropping.
